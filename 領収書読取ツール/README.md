# 🧾 領収書読取ツール（ローカル・API課金なし）

スキャンした領収書PDF（1ページに複数枚・向きバラバラ・種類混在OK）を読み取り、
**経費入力表の様式でExcel下書き**を作ります。人が確認・修正して使う「下書き」ツールです。

- 完全ローカル／オフライン。**外部送信なし・従量課金なし**。
- OCR本体（Tesseract 日本語）は同梱（管理者インストール不要）。
- 画像対応LLM（Ollama）が起動していれば**金額・相手先を高精度**に抽出。無くてもOCRで動きます。

---

## 使い方（クライアント＝配布版）

配布ZIPには **Python同梱(_runtime)・OCR同梱(_ocr)** が入っているので、Pythonのインストールは不要です。

1. 受け取ったZIPを **右クリック →「すべて展開」**（ZIPのままでは動きません）。
2. （精度を上げるなら任意）**`Ollama準備.bat`** を一度だけ実行 → 画像LLMとモデル(約3GB)を自動導入。
   - やらなくてもOCRで動きます（金額精度は控えめ）。
3. 読みたいPDFを **`01_input`** に入れて、**`読取実行.bat`** をダブルクリック。
4. `02_output\経費入力表_取込.xlsx` の **A〜I列をコピー → 経費入力表へ貼り付け**。

## 使い方（開発者＝Python導入済みPC）

1. **初回だけ**：`初回準備.bat`（`.venv`を作成）※配布版は不要（_runtimeを使う）
2. PDFを **`01_input`** に入れる。
3. **`読取実行.bat`** をダブルクリック。
4. `02_output\経費入力表_取込.xlsx`（シート「領収書取込」）に結果が**追記**されます。
   - **黄=新規で追加した行 ／ 赤=⚠要手入力**（手書き・読取困難）。先頭に確認欄 ☐。
   - 各行に**切り出し画像**とOCR抜粋が付くので、目で確認しながら修正できます。
   - 画面と `02_output\取込レポート.txt` に、手書き検知した該当PDF/番号が出ます。

> 経費入力表の様式（月／日付／相手先／内容／支払 …）に合わせています。確認後、
> 本番の経費入力表へ転記してください（＝この出力を“育てていく”下書き）。

---

## できること / 限界

- ✅ 1ページ内の**複数レシートを自動分割**、**上下逆さま等を自動補正**
- ✅ **金額・相手先・日付・種別**を抽出（LLM併用時は特に金額が正確）
- ⚠ **手書き（精算書・赤ペン）は自動化困難** → 「⚠要手入力」でフラグ。必ず人が確認
- ⚠ スキャンOCRは誤読が出ます。**下書き→人が確認**の運用が前提

---

## 精度を上げる：Ollama（任意）

金額・相手先の精度を上げるには、ローカル画像LLM「Ollama」を使います（無料・オフライン）。

1. https://ollama.com からダウンロードして導入（ユーザー領域・管理者不要）。
2. コマンドプロンプトで日本語対応の軽量モデルを取得：
   ```
   ollama pull qwen2.5vl:3b
   ```
3. 以降、`読取実行.bat` を実行すると自動でLLMを使います（起動していれば）。

> 目安：CPUで1枚あたり数秒。このPC（32GB RAM）なら快適。
> ※ Intel Arc GPUを速度に使いたい場合は「IPEX-LLM版Ollama」が必要（任意・上級者向け）。

### モデル比較（任意）
`初回準備`後、環境変数 `RECEIPT_LLM_MODEL` で切替できます（例：`minicpm-v`、`qwen2.5vl:7b`）。
`RECEIPT_USE_LLM=0` にするとLLMを使わずOCRのみで動きます。

## 配布物の作り方（メンテ担当者のみ）

1. `98_dist\配布ランタイム作成.ps1` を実行 → `_runtime`（Python同梱）を作成
2. `_ocr`（Tesseract同梱）がある事を確認（無ければ README 下部の手順で用意）
3. `98_dist\配布ZIP作成.ps1` を実行 → デスクトップに配布ZIPが出来る
   （_runtime・_ocr・コード・batを同梱／.venv・データ・98_dist は除外）
4. ZIPをクライアントへ。以降は上記「クライアント＝配布版」の手順。

> Ollama本体とモデルはサイズが大きいためZIPには含めません。配布先で
> `Ollama準備.bat` を1回実行して導入します（無くてもOCRで動作）。

## フォルダ構成
```
領収書読取ツール\
  01_input\        ← ここにPDFを入れる
  02_output\       ← 経費入力表_取込.xlsx / 取込レポート.txt
  04_work\         ← 切り出し画像（作業用）
  _ocr\tesseract\  ← OCR本体（同梱）
  src\             ← プログラム
  読取実行.bat / 初回準備.bat
```
